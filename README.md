# fast api 1

Контрольная работа 1 по дисциплине «Технологии разработки серверных приложений», РТУ МИРЭА.

## О приложении

Небольшой сервер на FastAPI. Он отдаёт приветствие и HTML-страницу, складывает два числа, возвращает пользователя и определяет совершеннолетие по возрасту.

Отзывы принимаются в двух вариантах. Простой сохраняет имя и текст как есть. Расширенный проверяет длину полей и отклоняет сообщения с запрещёнными словами.

Данные хранятся в памяти и сбрасываются при перезапуске.

## Маршруты

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/` | приветствие |
| GET | `/html` | HTML-страница |
| POST | `/calculate` | сумма двух чисел |
| GET | `/users` | текущий пользователь |
| POST | `/user` | имя, возраст и признак совершеннолетия |
| POST | `/feedback/basic` | отзыв без проверок |
| POST | `/feedback` | отзыв с проверкой длины и запрещённых слов |

## Как запустить

Потребуются Git и Python 3.10 или новее.

```bash
git clone https://github.com/vleypi/fast-api-1-mirea.git
cd fast-api-1-mirea
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

После запуска сервер доступен по адресу http://localhost:8000, интерактивная документация по адресу http://localhost:8000/docs.
